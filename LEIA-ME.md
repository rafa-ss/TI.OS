# Guia GPON — ajuste da ilustração

A imagem ilustrativa usa “GPON” nos destaques e informa que, no tipo 2, a etiqueta pode estar na frente ou atrás. A legenda e o texto alternativo também trazem essa orientação. Os números são exemplos; não devem ser copiados.

Importante: esta é uma ilustração adaptada, não a reprodução exata de uma etiqueta real. A identificação impressa varia conforme o fabricante; o número de série em aparelhos reais pode estar identificado como “SN”. GPON é a tecnologia, não uma sigla equivalente a número de série. O MAC é outro identificador e não deve ser copiado no lugar do número de série.

Faça backup e compare alterações próprias. Copie para os mesmos caminhos:
- `frontend/public/guia-gpon-onlite.png`
- `frontend/src/pages/InternetInstallation.jsx`

O nome do arquivo da imagem permanece igual para não quebrar a referência existente. Esta versão depende das entregas anteriores do módulo e da revisão dos textos. Reinicie ou atualize o frontend e gere novo build para produção. Se a imagem anterior continuar aparecendo, atualize a página ignorando o cache do navegador.
